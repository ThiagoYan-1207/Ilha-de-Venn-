# 🎪 Festival dos Conjuntos: O Desafio da Ilha de Venn

Protótipo de jogo educacional interativo desenvolvido em **HTML5, CSS3 e JavaScript** para a disciplina de **Matemática para Computação (AV2 - Unifor)**[cite: 1].

## 🎯 Objetivo Educativo
Transformar conceitos de Teoria dos Conjuntos, união, interseção e o Princípio da Inclusão-Exclusão em uma experiência lúdica e interativa ambientada em um festival de música[cite: 1].

## 🚀 Como Executar
1. Abra a pasta do projeto no **VS Code**.
2. Utilize a extensão **Live Server** para abrir o arquivo `index.html` no navegador.
